I'm Nick Newson, and this is the development log for
[fireEngine](https://github.com/nnewson/fireEngine-tutorial): a 3D engine built
in public, one working release at a time.

The code repository holds a step-by-step history of the engine. This site is
the companion narrative: the design decisions, rendering techniques,
experiments, dead ends, and lessons that do not fit neatly into a changelog.
